# Songjeong Landmark (WYNDHAM)

Single-page editorial website for a coastal landmark hotel in Busan Songjeong.
Six-section scroll-driven experience built with Astro + Tailwind v4 + GSAP/ScrollTrigger + Lenis.

This is the bootstrap scaffold only — implementation follows the plan at
`docs/plans/2026-04-27-001-feat-songjeong-landmark-site-plan.md`.

## Commands

```sh
pnpm install      # install dependencies
pnpm dev          # start dev server at http://localhost:4321
pnpm build        # static build to dist/
pnpm preview      # preview the production build
pnpm typecheck    # astro check
pnpm format       # prettier write
```
